## Installation

```sh
# via npm
npm install @tenedev/version-bump

# via yarn
yarn add @tenedev/version-bump

# via pnpm
pnpm add @tenedev/version-bump

# via bun
bun add @tenedev/version-bump

# via Deno (using JSR)
deno add jsr:@tene/version-bump

# via JSR
npx jsr add @tene/version-bump
```
